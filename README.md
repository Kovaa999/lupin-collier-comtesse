# Lupin et le collier de la comtesse

Un jeu d'aventure en mode texte, écrit en Python, dans l'esprit d'Arsène Lupin.

## Lancer le jeu
python lupin.py

## Principe
Entre dans l'hôtel, trouve les indices, ouvre le coffre et
finis avec le moins de points de suspicion possible.

## Notions utilisées
Variables, conditions, boucles while, listes, random.
